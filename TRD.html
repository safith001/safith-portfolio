1 Component Hierarchy & Server Boundary Map

Next.js 14+ App Router is designed to minimize client bundle payloads. Static presentation components remain pure Server Components (RSC), while client interactivity is strictly isolated into dedicated islands:

Component Layer Type File Location Technical Responsibility
[locale]/layout.tsx Server Component src/app/[locale]/layout.tsx Injects HTML root, locale attributes (lang, dir), anti-flicker theme script, and font classes.
Header.tsx Client Component src/components/layout/Header.tsx Sticky navigation bar, responsive mobile hamburger drawer, active link observer.
ThemeToggle.tsx Client Component src/components/ui/ThemeToggle.tsx Switches data-theme on document.documentElement; synchronizes with localStorage.
LanguageToggle.tsx Client Component src/components/ui/LanguageToggle.tsx Route-based locale switcher (/en, /ta, /ur) powered by next-intl router.
HeroSection.tsx Server / Client Hybrid src/components/sections/HeroSection.tsx Static title and badge SSR; client island for TypedText.tsx animated cycling headline.
ProjectsSection.tsx Client Component src/components/sections/ProjectsSection.tsx Grid of 4 projects featuring 3D hover perspective tilt and category filter toggles.
ContactForm.tsx Client Component src/components/ui/ContactForm.tsx Controlled inputs, client-side regex validation, async POST to Formspree API, toast feedback.

3 The 4-Theme CSS Custom Property Engine

Themes are implemented entirely through CSS custom properties attached to html[data-theme="..."]. This guarantees zero DOM reflows and zero component re-renders when switching themes.

🛡️ Flash of Unstyled Content (FOUC) Guard
To prevent a blinding white flash when a returning visitor opens the site in dark mode, an inline script in <head> immediately evaluates localStorage.getItem('safith_portfolio_theme') and sets document.documentElement.setAttribute('data-theme', theme) before the browser paints the first pixel.
4 Internationalization (i18n) & RTL Architecture

The application integrates next-intl with App Router middleware to handle localized routing (/[locale]/...) and automatic Right-to-Left (RTL) mirroring for Urdu:

Locale Language Direction (dir) Font Fallback Stack Layout Rules Enforced
en English (Default) ltr Plus Jakarta Sans, Inter, sans-serif Standard left-to-right flex/grid flows.
ta Tamil ltr Noto Sans Tamil, sans-serif Increased line-height (1.65) for Tamil glyph ascenders/descenders.
ur Urdu rtl Noto Nastaliq Urdu, sans-serif Reversed margins (ms-*, me-*), mirrored icons, flipped chevrons.
5 Motion Choreography & Performance Budget

All page transitions utilize Framer Motion with CSS hardware acceleration to maintain a steady 60 FPS on mobile and low-power hardware:

✨ Motion Animation Tokens
  • Fade In Up: opacity: [0, 1], y: [24, 0] (Duration: 0.5s, Ease: Cubic-Bezier)
  • Card Hover Tilt: scale: 1.015, y: -6px, Box-shadow elevation glow
  • Typing Cycler: Character delay: 60ms, Word pause: 2000ms, Backspace delay: 35ms
  • Reduced Motion Guard: Honors OS prefers-reduced-motion: reduce setting
⚡ Performance & Core Web Vitals Budget
  • Largest Contentful Paint (LCP): < 1.2s (Optimized WebP images via next/image)
  • Cumulative Layout Shift (CLS): 0.00 (Zero layout jumping via reserved aspect ratios)
  • First Input Delay / INP: < 50ms (Zero heavy blocking client JavaScript)
  • Total Bundle Size: < 95 KB gzip first-load JS transferred
