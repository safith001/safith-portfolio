2 Component Boundaries: Server (RSC) vs. Client

Next.js 14+ defaults to Server Components (RSC). Client Components ('use client') are strictly isolated to interactive islands:

Server Components (Zero Client JS)

• Runs at build time (SSG); outputs fast HTML.

• [locale]/layout.tsx (HTML structure, fonts)

• [locale]/page.tsx (Assembles all 7 sections)

• Footer.tsx (Static links, copyright)

• AboutSection.tsx (Static biography, metrics)

• ReferencesSection.tsx (Degree notes)

Client Components ('use client')

• Runs in browser; handles state & events.

• Header.tsx (Sticky scroll observer)

• ThemeToggle.tsx (4-theme selector)

• LanguageToggle.tsx (URL locale routing)

• TypedText.tsx (Animated role cycler)

• ContactForm.tsx (Validation & Formspree POST)

• ScrollReveal.tsx (Framer Motion viewport inView)

3 Data Flow: Decoupled Stores vs. UI Plates
🍽️ The Restaurant Menu Analogy
In a restaurant, the Menu (src/data/projects.ts) holds the food items and prices. The Plates (src/components/ui/ProjectCard.tsx) are the visual presentation. When you add a new project or change a description, you simply update the data array without risking breaking the UI design.
Data Store Type Contract Consuming Section Component Delivered Capability
src/data/projects.ts Project[] <ProjectsSection /> Renders 4 project cards with tags, statuses, and live links.
src/data/skills.ts SkillItem[] <SkillsSection /> Renders grouped badges across Languages, Frontend, QA, etc.
src/data/timeline.ts TimelineEntry[] <TimelineSection /> Renders chronological degree and internship milestones.
4 Scalability: How to Extend the Codebase
Extension Goal Files to Modify Execution Steps
Add a 5th Project src/data/projects.ts Append a new project object. The card and /projects/[slug] page are generated automatically at build time.
Add a 5th Theme globals.css, themes.ts Declare html[data-theme="new-name"] CSS variables and register the name in themes.ts. Appears in toggle immediately.
Add a New Language messages/, middleware.ts Add messages/[locale].json, register the code in middleware, and add the option to LanguageToggle.tsx.
