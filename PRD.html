3 Technology Stack & Rationale
Layer Technology Why This Tool Was Chosen (Defensibility)
Framework Next.js 14+ (App Router) Reinforces existing Next.js skills from PeerConnect. Provides fast SSG/SSR, native SEO optimization, and automatic Vercel deployment.
Styling Tailwind CSS 3 Utility-first styling mapped to CSS Custom Properties (var(--bg-...)). Enables instantaneous theme switching without DOM rebuilding.

Deployment Vercel (Free Tier) Zero-config continuous deployment from GitHub with edge caching and automatic preview branches.

7 Multilingual & Internationalization Engine

The site is architected for global accessibility with route-based localization (/[locale]/...) managed by next-intl.

Language Code Direction Launch Phase Special Architectural Requirements
English en LTR Tier 1 (Launch) Default base translation file (messages/en.json).
Tamil ta LTR Tier 1 (Launch) Unicode Noto Sans Tamil typography support.
Urdu ur RTL Tier 1 (Launch) Right-to-Left layout switching, CSS logical properties (ms-*, me-*).
Sinhala, Hindi, German, Russian, etc. 9 codes LTR/RTL Tier 2 (Roadmap) Decoupled JSON dictionaries allow seamless addition without code changes.
