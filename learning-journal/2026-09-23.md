### The Layout Problem You Spotted 👀

The first version of the skills section had all 5 groups arranged in a 3-column layout (like a 3-column newspaper). But you looked at it and immediately said:

> *"The sizes are not aligned — the Mobile group only has 2 skills but the box is stretching to match the tall ones next to it."*

You were completely right. When you force things into equal columns, the shorter boxes get stretched to fill the gap — leaving a big ugly empty space.

**The fix:** We changed it to a **stacked layout** — one clean rectangle, then another clean rectangle below it, and so on. Like pancakes stacked on a plate. Each rectangle only takes up as much height as it actually needs. No empty gaps, no stretching. Clean.

## 💡 New Things You Learned Today (In Plain English)

### `useMemo` — The "Don't redo the same work twice" trick

Inside your website code, every time something changes on the screen (like clicking a tab), React re-runs a lot of code. Some of that code is expensive — like filtering through your list of 20 skills.

`useMemo` is like saying: *"Hey React, only filter the skills again if the selected tab actually changed. If nothing changed, just reuse the answer from last time."*

Real-world version: Imagine you run a café and someone asks "what cakes do you have today?" You write the list. If someone else asks 5 minutes later and nothing changed, you just hand them the same list. You don't go back to the kitchen to re-check. That is `useMemo`.

### TypeScript Union Types — The "only these options allowed" lock

We defined the proficiency levels like this in the code:

```
type ProficiencyLevel = 'Core Foundation' | 'Applied in Projects' | 'Industrial Internship'
```

This means: if anyone accidentally types `'Expert'` or `'Beginner'` or even `'core foundation'` (lowercase) — TypeScript immediately shouts an error and refuses to run. It only accepts exactly those 3 options.

Real-world version: It is like a vending machine that only accepts specific coins. You cannot put in a button or a bottle cap. The machine rejects it instantly.

### CSS Grid vs. Stacked Layout

`grid grid-cols-3` = Forces 3 equal boxes side by side. They all become the same height as the TALLEST one. This creates gaps in shorter boxes.

`space-y-6` = Just stacks things vertically. Each box is only as tall as it needs to be. Clean. Natural. No gaps.
